# Sprint 03 - Templates

## Goal

Provide customizable invitation templates.

## Features

* Template catalog
* Template preview
* Template selection

## Entities

Template

Fields:

* Id
* Name
* Theme
* ThumbnailUrl

## Security

* Validate uploaded images
* Restrict file extensions
* Restrict file size
* Malware scanning preparation

## Acceptance Criteria

* User selects template.
* Invalid files are rejected.
